# 🛍️ ShopSphere

A modern full-stack e-commerce web application built using the MERN stack.

ShopSphere provides a complete shopping experience with user authentication, product browsing, search, filtering, cart management, checkout, and order tracking.

## 🚀 Live Features

- User registration and login
- JWT-based authentication
- Protected routes
- Product listing
- Product details
- Product search
- Category filtering
- Price sorting
- Pagination
- Shopping cart
- Add/remove products
- Update product quantities
- Clear cart
- Checkout
- Shipping information
- Order placement
- Order history
- User profile
- Admin product management
- Responsive modern UI
- MongoDB product database
- 50+ seeded products

## 🛠️ Tech Stack

### Frontend
